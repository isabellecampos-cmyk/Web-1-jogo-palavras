# Jogo de Adivinhação de Palavras
Projeto desenvolvido na disciplina de Desenvolvimento de Aplicações Web I.

## Integrantes
- Isabelle Campos silva 

## Como jogar
Digite uma letra e clique em **Tentar** (ou pressione **Enter**).
O objetivo é descobrir a palavra secreta antes de acabar as tentativas.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Funcionalidades
- Palavra aleatória (10 palavras disponíveis)
- Dica para cada palavra
- Controle de tentativas (6)
- Lista de letras já utilizadas
- Bloqueio de letras repetidas
- Mensagem de vitória e derrota
- Botão de nova partida
- Envio por Enter (desafio extra)
